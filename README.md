# Antigravity V2 Decision Export Utility

The **Antigravity V2 Decision Export Utility** ([agv2_export_conversation.py](file:///home/$USER/antigravity/agv2_sprint2readme/agv2_export_conversation.py)) is a Python command-line tool designed to extract the conversational history, developer agent thoughts (reasoning), and generated artifacts of a Google Antigravity V2 coding session.

By exporting these conversations to Markdown, teams can commit decision records directly into version control (e.g., Git repositories) alongside their codebase changes. This provides a transparent, auditable history of the change management decisions and reasoning that led to a specific implementation.

---

## Why Use This Utility?

The Antigravity V2 agent platform maintains a local knowledge base of activities organized by **Projects** and **Conversations**. By default, these details are stored in the user's home directory under `~/.gemini/antigravity`.

If a developer's environment is reset or lost, the underlying reasoning logic, prompts, and temporary developer thoughts are lost. Running this utility exports these details into a portable Markdown document that can be committed to your repository as part of a pull request or code review.

---

## Features

- **Automated Parsing**: Reads protobuf summaries (`agyhub_summaries_proto.pb`) and scans local conversation trajectory databases.
- **Thought Extraction**: Identifies and extracts reasoning blocks (`Thought` tags) without cluttering the output with raw tool execution logs.
- **Artifact Embedding**: Automatically discovers and embeds workspace artifacts (such as `implementation_plan.md` or `walkthrough.md`) as code blocks.
- **Fuzzy Search**: Matches conversations either by their exact 36-character UUID or a case-insensitive search term in their title.
- **Custom Database Pathing**: Allows specifying a custom directory path for local or backup databases.

## Command Line Interface (CLI)
```bash
# Export a conversation to Markdown
python3 agv2_export_conversation.py -p <project_name> -c <conversation_identifier> [options]

# List all available projects
python3 agv2_export_conversation.py --list

# List all conversations within a project
python3 agv2_export_conversation.py -p <project_name> --list
```

### Arguments & Options

| Option | Long Flag | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `-p` | `--project` | Conditional | N/A | Name of the project (e.g. `atc`). Required unless `--list` is used without `-p`. |
| `-c` | `--conversation` | Conditional | N/A | The conversation UUID or search term within title. Required for exports. |
| `-l` | `--list` | No | `False` | Lists available projects, or lists conversations within a specified project (`-p`). |
| `-d` | `--db-dir` | No | `~/.gemini/antigravity` | Path to the directory where the Antigravity database is stored. |
| `-o` | `--output-dir` | No | `.` | The target directory where the exported Markdown file will be written. |
| `-h` | `--help` | No | N/A | Displays the help message and exit. |

## Output Structure

The generated markdown file is saved under the naming convention:  
`[project]_[timestamp].md` (e.g. `atc_2026-07-14T21-36-45Z.md`) and follows this structure:

1. **Title**: The conversation title is set as a level-1 header (`# <Title>`).
2. **User Prompt**: The user's original request is formatted in a blockquote block (`>`).
3. **Reasoning**: Every reasoning thought block generated by the agent is listed in sequential order under a `## Reasoning` section with timestamps.
4. **Artifacts**: If the agent generated workspace files (e.g. `walkthrough.md`, `implementation_plan.md`), they are appended as subsections:
   ```markdown
   ## implementation_plan.md
   ```json
   [Embedded File Content]
   ```
   ```
